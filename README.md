# 品管（土建）刷題網站

## 功能
- Excel 題庫完整匯入
- 依課程單元篩選
- 10 / 20 / 50 / 100 / 全部題目
- 依序或隨機出題
- 即時顯示答對／答錯與正確答案
- 進度條與成績統計
- 深色／淺色模式
- 純 HTML/CSS/JavaScript，無需安裝程式

## GitHub Pages
1. 建立 GitHub repository。
2. 將 `index.html` 上傳到 repository 根目錄。
3. 到 **Settings → Pages**。
4. Source 選 **Deploy from a branch**。
5. Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
6. 等待幾分鐘後即可取得網站網址。
